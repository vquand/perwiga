# Genshin Impact module

- Module ID: `genshin-impact`.
- Scope: Genshin Impact only.
- Follow [games/AGENTS.md](../AGENTS.md) and the root data-safety rules.
- Keep Genshin-specific entity types, relations, fields, event sources, parsers, fixtures, migrations, and custom UI in this module.
- Do not assume an API, RSS feed, entity taxonomy, region schedule, or time zone until it is documented from a confirmed source.
- Shared HoYoverse helpers are allowed only for behavior proven common; do not depend directly on the Honkai: Star Rail module.
- Confirmed source boundary checked on 2026-08-24: the official [global character directory](https://genshin.hoyoverse.com/en/character/mondstadt) loads its regional catalogs from HoYoverse's public website content service. The official site bundle declares app ID `32`, content key `a1b1f9d3315447cc`, detail channel `407`, and region channels `403`, `404`, `405`, `406`, `653`, `934`, and `1221` for Mondstadt through Snezhnaya. These are website content identifiers, not a general game-data or player-account API.
- The curated [`data/characters.json`](data/characters.json) snapshot contains the 118 records returned by those seven official regional channels on 2026-08-24. Preserve each `official_content_id` and `source_key` across additive refreshes. English is the catalog anchor; Traditional Chinese and Vietnamese records join by the same official content ID. Missing localizations must remain explicit `locale_gaps` rather than falling back silently.
- The global directory supports official Traditional Chinese (`zh-tw`), not Simplified Chinese (`zh-cn`). Never store the Traditional Chinese value as `official_original_name`, automatically convert it to Simplified Chinese, or otherwise present it as the original mainland localization. A future Simplified Chinese source must be separately confirmed and provenance-labeled.
- Run [`scripts/fetch-characters.py`](scripts/fetch-characters.py) to refresh the reviewable JSON snapshot. The fetcher validates untrusted responses, paginates, bounds timeouts/retries/response sizes, joins locales by content ID, writes atomically, and refuses to shrink an existing catalog unless `--allow-shrink` is explicit after review. It never opens SQLite.
- Run [`scripts/fetch-character-thumbnails.py`](scripts/fetch-character-thumbnails.py) to fill `assets/characters/` from the snapshot's first-party HoYoverse URLs. The downloader allowlists hosts, validates filenames and image signatures, bounds concurrency and response size, and never overwrites an existing valid asset.
- The runtime module exposes the source-confirmed `Character` type plus the required shared `NPC` and `Region` types. It supplies semantic presentation tokens and is registered by the CLI and UAT composition roots.
- Character imports use the core's additive sourced-entity transaction with provider/source identity keys. Repeat imports never replace an existing entity, preserving personal edits. Store official Traditional Chinese as a provenance-labeled `zh-Hant` alias. Until a confirmed Simplified Chinese source exists, repeat the official English catalog anchor in the schema-required original-name field and state that limitation in `other_information`.
- Module-owned Character presentation resolves the stable HoYoverse source key to the bundled local PNG, source-confirmed region facet, bundled local region emblem, and the fully covered [`data/character-presentation.json`](data/character-presentation.json) rarity snapshot. Keep 4-star purple and 5-star gold borders distinct. Aloy remains a 5-star Character but uses the red collaboration border backed by the official HoYoverse support article recorded in that snapshot. Keep rarity in the thumbnail badge. Render region as its monochrome emblem in the right-side context beside the Character type, preserve the region name as accessible text and a load-error fallback, and never put region text or icon over the portrait. Keep exact emblem provenance and checksums in [`assets/regions/README.md`](assets/regions/README.md); the region-emblem catalog is presentation evidence only. Unknown or malformed source keys must return no presentation metadata and must never become filesystem paths.
- Current state: the title-owned character fetch/snapshot, local-thumbnail pipeline, transactional SQLite importer, and presentation wiring are implemented and tested. The runtime module is registered, and UAT setup creates one idempotent Genshin library work and imports the bundled Character snapshot. Additional title-specific schemas/facets and automatic feed or scheduled-event adapters remain intentionally unimplemented until separately scoped and sourced.
